# 🃏 NEURAL_ARCHITECT v4.0

A high-fidelity, professional-grade Blackjack training environment with a "Neural/Cyber" aesthetic. Designed to hone your decision-making and card-counting skills using real-time diagnostics and optimal strategy heuristics.

![Neural Architect Black Jack Trainer](https://kevinbae.github.io/Neural-Architect-Black-Jack-Trainer/)

## 🚀 Features

- **Optimal Heuristic Engine**: Real-time evaluation of every move against mathematically proven basic strategy.
- **Neural HUD**: Immersive heads-up display providing tactical explanations and win probabilities for every action.
- **Cognitive Accuracy Tracking**: Advanced analytics that breakdown your performance by hand type (Hard, Soft, Pairs).
- **Phase 4 Diagnostic Node**: Integrated Hi-Lo card counting engine with live True Count and Running Count calibration.
- **High-Fidelity UI**: Premium "Neuromancer" inspired theme featuring glassmorphism, dynamic animations, and atmospheric neon effects.
- **Casino Simulation**: Customizable rules including H17/S17, multi-deck shoe management, and realistic deck penetration.

## 🛠️ Technology Stack

- **Framework**: React 19 (TypeScript)
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: GitHub Actions (Configured for GitHub Pages)

## 🏗️ Getting Started

### Prerequisites

- Node.js (v20 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/black-jack-trainer.git
   ```
2. Navigate to the directory:
   ```bash
   cd black-jack-trainer
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```

### Production Build

Create an optimized distribution build:
```bash
npm run build
```

## 📡 Deployment

This repository is pre-configured for **GitHub Pages**.
1. Push your code to the `main` or `master` branch.
2. Go to **Settings > Pages** in your GitHub repo.
3. Select **GitHub Actions** as your build and deployment source.
4. The deployment will trigger automatically.
